# Sécurité / Security

## Signaler une faille

Si tu trouves une faille de sécurité dans netinv, **n'ouvre pas d'issue publique**. Utilise plutôt l'onglet **Security → Report a vulnerability** du dépôt (signalement privé), ou contacte [@malolefoll](https://github.com/malolefoll) en privé.

Indique la version concernée, comment reproduire le problème et son impact. Tu recevras une réponse dès que possible.

## Reporting a vulnerability

Please **do not open a public issue**. Use the repository's **Security → Report a vulnerability** tab (private report), or contact [@malolefoll](https://github.com/malolefoll) privately.

## Versions prises en charge / Supported versions

Seule la dernière version publiée reçoit des correctifs. / Only the latest release receives fixes.
